# Ответы на домашнюю работу №1
## 1. Смысл одной строки в файлах данных:
1. **wells.csv** - одна строка соответствует одной наблюдательной скважине (координаты, отметки и измерения).
2. **layers.xlsx** - одна строка соответствует одному геологическому слою (мощность, пористость, фильтрационные свойства).
3. **pumping_test.txt** - одна строка соответствует одному моменту времени (шагу замеров) в процессе откачки.
## 2. Ответы на вопросы:
1. **Чем DataFrame отличается от массива NumPy?**
   DataFrame (из Pandas) - это двумерная таблица с именованными столбцами разных типов данных, предназначенная для работы с гетерогенными данными. Массив NumPy - это однородная многомерная сетка данных одного типа (обычно числового), оптимизированная под быстрые матричные и векторные вычисления.
2. **Что означают две величины в shape массива (13, 2)?**
   Первое число (13) означает количество строк (моментов времени измерений), а второе (2) - количество столбцов (переменных давления: на границе и в скважине).
3. **Почему pressure * 1_000_000 не требует цикла for?**
   Благодаря векторизованным операциям NumPy и Pandas, которые выполняют математические действия на уровне оптимизированного кода на языке C сразу со всем массивом данных за один проход.
4. **Что выбирает срез array[::2]?**
   Срез выбирает каждый второй элемент из массива, начиная с нулевого индекса с шагом 2 ([0, 2, 4, ...]).
5. **Что содержится в логической маске?**
   Логическая маска представляет собой массив булевых значений (True и False), где True соответствует элементам, удовлетворяющим условию отбора, а False - не удовлетворяющим.
6. **Зачем после сохранения загружать массив обратно?**
   Обратная загрузка используется для контроля целостности данных - чтобы убедиться, что файл записался корректно, не был поврежден и полностью совпадает с исходным массивом через проверку 
p.allclose.
7. **Какие файлы являются исходными, а какие создаются программой?**
   Исходными являются файлы в папке data/raw/hw01/ (wells.csv, layers.xlsx, pumping_test.txt), которые генерируются скриптом generate_data.py. Программой создаются все остальные файлы: очищенные данные, сводные таблицы Excel, бинарные файлы NPY/NPZ и текстовые отчеты в data/processed/hw01/ и exports/hw01/.
