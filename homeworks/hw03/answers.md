1. **Почему моменты времени можно соединять линией?**
   Потому что временные ряды упорядочены и отражают непрерывное физическое изменение процесса во времени.
2. **Почему наблюдательные скважины не нужно соединять?**
   Скважины являются независимыми дискретными объектами пространственного распределения, а не последовательными точками одного процесса.
3. **Когда уместна столбчатая диаграмма?**
   Когда нужно сравнить дискретные категориальные значения или параметры по отдельным независимым объектам (например, скважинам).
4. **Что показывает линия внутри boxplot?**
   Медиану распределения данных (значение, разделяющее выборку ровно пополам).
5. **Чем violin plot отличается от boxplot?**
   Violin plot дополнительно отображает оценку плотности вероятности распределения данных (их форму), а не только квартили.
6. **Почему круговая диаграмма не подходит?**
   Потому что давления не являются долями одного общего целого (суммирующимися до 100%).
7. **Зачем все связанные массивы сортировать одним порядком?**
   Чтобы сохранить взаимное соответствие данных (чтобы id скважины строго соответствовал ее радиусу и давлению).
